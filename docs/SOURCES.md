# Источники и provenance

## Byte source

Единственным источником байтов для этой сборки был переданный пользователем файл `Hang-On (Europe).sms` с SHA-256:

```text
0d35d0e232d64e714fa5d07e45acaf01ea9fb5a8f88fe9ac8018719ac2818d6f
```

Из него были выделены code/data ranges и бинарные assets. Собранный ROM проверен против него побайтно.

## Семантическая сверка

Для проверки назначения функций использовалась публичная комментированная дизассемблия японской ревизии из проекта:

```text
https://github.com/maxim-zhao/hangon-sms-enhanced
```

Она не является источником байтов и не включена в проект. Сопоставление делалось по нормализованным последовательностям Z80-инструкций: адреса, непосредственные значения переходов и различия layout игнорировались только на этапе поиска эквивалентных функций. Имя переносилось лишь при достаточно уверенном совпадении; сомнительные gameplay routines оставлены с нейтральными именами.

Такой подход не смешивает Japanese и European ROM revisions и не влияет на byte-exact verification.
